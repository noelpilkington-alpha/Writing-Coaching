Q3: Stay on the Same Topic

When expanding a sentence, add detail about the SAME thing

The question asked you to expand this sentence by adding another detail:

Original
A pumpkin seed is flat and white.
YOU WROTE
A pumpkin seed is flat and white, as the pumpkin grows pumpkin vines grow bright yellow flowers.

You added a detail, but it jumps to a new topic — vines and flowers. The sentence was about what a seed looks like, so the new detail should describe the seed too.

Tap to see the improved version
Read the explanation above first
BETTER
A pumpkin seed is flat and white, with a hard outer shell that protects the tiny plant inside.
STAY ON THE SAME TOPIC
When expanding a sentence, the new detail should be about the same thing. Ask yourself: "What else can I say about THIS?"

In this case, the sentence was about a pumpkin seed, so the detail should describe the seed too — not switch to vines.

Pattern:

"The pumpkin is round" → "The pumpkin is round and can grow as big as a basketball."
"The pumpkin is round, and the farmer has a red tractor." ← switches topic!
