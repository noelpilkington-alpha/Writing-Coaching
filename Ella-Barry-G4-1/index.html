THE RULE: SHOW, THEN SO WHAT
The question asked how the events cause Cody to change. So each supporting detail is a SHOW, an event in the story’s own words, followed by a SO WHAT: This shows… what the event proves about Cody’s opinion. The check: read your paragraph and ask after each sentence: is this what happened, or what it proves? If every sentence is what happened, you have retold the story. Count the This shows. THE ONE POINT IN Q5
“His dedication has transformed the school, because of his efforts, enrollment has doubled, and more students are now attending college.”
The instruction asked for because, but or so as the joining word. Because of is not a joining word, so the comma after school is holding two sentences together. His dedication has transformed the school, so enrollment has doubled and more students are now attending college.
