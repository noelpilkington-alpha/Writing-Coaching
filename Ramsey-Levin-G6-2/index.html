Detail + Explanation Depth

The difference between 15/20 and 18+/20

Ramsey, here is the pattern that separates a 15/20 essay from an 18+/20 essay. Both essays can have the same ideas. The difference is how deeply each idea is developed.

The Detail + Explanation Pattern
POINT State your argument or claim
DETAIL Name a specific detail from the passage that supports your point
EXPLAIN Explain what that detail shows or why it matters to your argument

Here is what this looks like in practice for the Animated Movies prompt:

UNDERDEVELOPED (15/20 level)
"Animated movies have evolved because technology has improved over the years. They used to be simple but now they are very advanced."
FULLY DEVELOPED (18–20/20 level)
"Animated movies have evolved because technology has improved over the years. For example, the passage describes how early animated films like Steamboat Willie used hand-drawn frames that required artists to draw each movement individually. This shows that early animation was limited by how much physical labor artists could put in, which restricted the complexity of the visuals. In contrast, modern films use computer-generated imagery that allows animators to create entire photorealistic worlds. This demonstrates that technological advances removed the physical limits of animation, enabling stories that would have been impossible to tell visually in earlier decades."
THE DIFFERENCE
Both versions make the same point. But the developed version names specific details (Steamboat Willie, hand-drawn frames, computer-generated imagery) and then explains what each detail shows about the evolution of animation. That explanation is where the points live.

THE FORMULA FOR EACH BODY PARAGRAPH
1. Topic sentence — state your point
2. "For example, the passage describes/states/shows..." — name the specific detail
3. "This shows/demonstrates/reveals that..." — explain what it means for your argument
4. Optional: a second detail + explanation cycle for extra depth
5. Closing sentence — link back to your thesis
